
==== Init

[source]
.Command
--
init
--

One has to initialise the backend system by calling this command before any other command can be used.

[caption=""]
.Arguments
[cols="1,1"]
|===
| requested-version | must be currently always number 1
|===

[caption=""]
.Response
[cols="1"]
|===
| None
|===
