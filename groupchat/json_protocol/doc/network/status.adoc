[source]
.Command
--
network.status
--

Return status of the connection (later on there will be many servers but for now only one is used and hence no arguments).

[caption=""]
.Arguments
[cols="1"]
|===
| None
|===

[caption=""]
.Response
[cols="1,1"]
|===
| status | Status of the connection, one of "disconnected", "connected", "connecting".
|===
