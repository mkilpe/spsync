=== connect / disconnect

No argument, answer `{}`. `connect` needs an account; it opens the packet server
connection (contact requests and invitations travel through it) and connects every
known chat. `disconnect` closes them. Both may be called again.

=== Connection notifications

`state_change` with `type` `connection`:

[cols="1,3"]
|===
| connection | `online` or `offline`
| error      | (offline only, optional) the error object of a connection lost with an error
|===
