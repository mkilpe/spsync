[source]
.Command
--
chat.list
--

List chats.

[caption=""]
.Arguments
[cols="1,1"]
|===
| return-data | 0 or 1 to determinate if the result should contain data associated per chat.
|===


[caption=""]
.Response
[cols="1,1"]
|===
| users | Array of chats, see table below
|===

[caption=""]
.Chat data in response array
[cols="1,1"]
|===
| id     | id of the chat as integer
| data   | (Optional) data associated with the chat
|===
