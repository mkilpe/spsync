[source]
.Command
--
chat.create
--

Create a chat

[caption=""]
.Arguments
[cols="1,1"]
|===
| members | array of contact ids
| data    | Arbitrary data one wants to save for the chat, e.g. chat name
|===

[caption=""]
.Response
[cols="1, 1"]
|===
| id | Integer id for this chat that can be used later on for other commands
|===
