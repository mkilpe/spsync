[source]
.Command
--
chat.send
--

Create a chat

[caption=""]
.Arguments
[cols="1,1"]
|===
| id      | Id of the chat
| message | Message to send, encoded in UTF-8.
|===

[caption=""]
.Response
[cols="1, 1"]
|===
| message-id | Integer that is message id, identifies this message uniquely in this chat (and only in this chat).
|===
