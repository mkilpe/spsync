[source]
.Command
--
contacts.list
--

List contacts.

Each contact has a status that indicates if adding the contact was fully successful and the contact can be used
as member of a chat. This currently idicates if querying the public key for the user was successful.

[caption=""]
.Arguments
[cols="1,1"]
|===
| return-data | 0 or 1 to determinate if the result should contain data assiciated per contact.
|===

[caption=""]
.Response
[cols="1,1"]
|===
| users | Array of contacts, see table below
|===

[caption=""]
.Contact data in response array
[cols="1,1"]
|===
| id     | id of the contact as integer
| status | Status of the contact, one of the following strings: "Pending", "Failed", "Ok"
| data   | (Optional) data associated with the contact
|===
