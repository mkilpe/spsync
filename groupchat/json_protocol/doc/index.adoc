= Secure Path GroupChat JSON API
Version 0.2, 2026-09-25
:toc: right
:toclevels: 3

The API a front end drives the groupchat core with: the functions of
`json_manager` (`json_protocol/json_manager.hpp`), each taking one JSON argument and
answering with JSON, and the notifications the core sends back through its callback.
The Android adapter (`groupchat/android`) exposes exactly this: `call(name, json)` and
the listener's `onEvent(type, json)`.
