= tests
* every fixed test port (42750-42830) lies inside Linux's ephemeral range (32768-60999): an
  outgoing connection of ANY process can sit on one and the test that binds it fails with
  "bind: Address already in use" (seen 2026-09-21: another process held 42780 for many
  minutes, "s2s replica creates the storage on first contact" failed every run and took
  "s2s bootstrap a new replica" with it). Move the test ports below 32768 or reserve them
  (net.ipv4.ip_local_reserved_ports); a test that throws in start() should not disturb the next

  crypto ceiling (~2850/s single-threaded). ML-DSA-65 verify itself is 114us.
  Benchmark: test_spsync_server_lib "[.performance]" (hidden tag, not run by ctest)

* improve event handling (i.e. try to remove blocking mutexes with strands etc)

  batch budget is 1 MiB with at least two records per batch (a fetch continues FROM the
